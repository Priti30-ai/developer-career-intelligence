# Developer Career Intelligence System

AI-powered platform for developer skill assessment, career intelligence, job matching, and repository architecture analysis.

## Project Objective

The system analyzes developer evidence from sources such as GitHub, resumes, coding profiles, and job descriptions to generate evidence-based career insights.

## Core Areas

- Developer Skill Assessment
- Resume vs Code Evidence Analysis
- Job Description Matching
- Skill Gap Detection
- Personalized Career Roadmap
- Repository Architecture Analysis
- Repository Q&A using RAG
- AI-powered Developer and HR Intelligence
